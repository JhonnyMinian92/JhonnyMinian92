## 👋 Sobre mí

Soy **Jhonny Darwin Miñan Girón**, ingeniero de sistemas y profesional de software de Ecuador.

Mi trayectoria no comenzó en una sola capa del stack. Desde aproximadamente **2010** he recorrido desarrollo independiente, soporte técnico, hardware, redes, servidores, análisis de sistemas, emprendimiento y desarrollo de software en producción. Me interesa construir software que no solo funcione como una demo, sino que pueda mantenerse, integrarse con otros sistemas y convertirse en producto.

# 🧠 Mnemosine

**Mnemosine** es la pieza central de la arquitectura de memoria y contexto de EcuApp.

Su objetivo es proporcionar una capa reutilizable para que proyectos y agentes de IA puedan trabajar con conocimiento persistente, reglas, tareas, requerimientos y skills sin tener que duplicar toda esa información dentro de cada repositorio.

La arquitectura contempla diferentes tipos de memoria:

- **Short-term / Working Memory**
- **Long-term Memory**
- **Episodic Memory**
- **Semantic Memory**
- **Procedural Memory**
- **Identity / Entity Memory**

Y una arquitectura de **skills reutilizables** para:

- roles de desarrollo;
- lenguajes y versiones;
- arquitecturas web, mobile y B2B;
- UI/UX;
- bases de datos;
- patrones frontend;
- patrones backend;
- ciberseguridad;
- agentes y automatización.

La idea fundamental es que cada proyecto pueda consultar mediante una API **solo el contexto que necesita**, manteniendo una fuente central de conocimiento y evitando duplicación.

🔗 **Repositorio:** [EcuApp/mnemosine](https://github.com/EcuApp/mnemosine)
